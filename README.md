# Semillas de Sabor

Landing page interactiva en español para acompañar a una niña en su camino hacia la gastronomía profesional.

## Archivos
- `index.html`: estructura, contenido y enlaces de formación.
- `styles.css`: diseño responsive con paleta cálida.
- `script.js`: seis etapas interactivas, misiones y progreso guardado en el navegador.

## Abrir localmente
Abre `index.html` en cualquier navegador moderno. No requiere dependencias, compilación ni servidor.

## Publicar en GitHub Pages
1. Crea un repositorio público llamado `semillas-de-sabor`.
2. Sube los tres archivos a la raíz del repositorio.
3. En **Settings → Pages**, elige **Deploy from a branch**, rama `main`, carpeta `/ (root)`.
4. Tras desplegarse, la URL habitual será `https://TU-USUARIO.github.io/semillas-de-sabor/`.

## Nota
Las edades son orientativas. Las actividades con cuchillos, hornos y fuego deben realizarse con supervisión adecuada. Los programas académicos, requisitos, becas y costos pueden cambiar; comprueba la información con las instituciones.
